# Blind test set

The held-out test set contains 8 chats and 11 requests (10 scored requests and 1 Aminobots staff-to-staff internal request). It was authored by Ch Pranav, drafted with Claude (not the build agent), and Telugu-reviewed by Ch Pranav. The synthetic data is licensed under CC BY 4.0.

This set is held out for evaluation and must never be used for development or prompt tuning.

# ADR-0006: Disjoint test pools, held-out templates, human challenge set, leakage check

- **Status:** Accepted
- **Date:** 2026-10-10

## Context
A system tuned on its own generator can score well on generated data and still fail on real
chat. Test results must reflect generalisation (SPEC §13.6).

## Decision
- **dev:** seeds 1000–1999, persona/outlet pool A, all templates except three held out.
- **test:** seeds 5000–5999, disjoint pool B, all templates including the held-out
  `photo_caption_request`, `two_requests_one_message` and `vouching`; generated by the human.
- **challenge:** 20–30 human-written transcripts with a native Telugu speaker, including both
  mandated scenarios verbatim.
- test and challenge are frozen once committed; `data/MANIFEST.json` records sha256 per file.
- `scripts/check_leakage.py` (8-gram hash overlap) proves no test/challenge text is in `prompts/`
  (INV-6).

## Alternatives considered
None recorded in SPEC.

## Consequences
- The pass rule is evaluated on test and challenge, never dev (SPEC §14.4).
- Nothing may read the frozen sets except `eval/run_eval.py` (CLAUDE.md invariant 6; ADR-0013).
